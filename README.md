# Asteroid Shiba

Página de Asteroid, el Shiba de Polaris Dawn: cuenta regresiva, gráfica de cohete y la moneda de la comunidad en Solana.

## Abrir

`asteroid.html` es la página completa. Ábrela en el navegador.

La misma página está publicada en GitHub Pages: https://borincanopr.github.io/asteroid-shiba/ (`index.html` en la raíz del sitio).

## Desarrollo

```bash
npm install
npm run dev
```

El servidor local queda en el puerto 8080.
