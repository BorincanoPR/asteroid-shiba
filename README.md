# Asteroid Shiba

Página de Asteroid, el Shiba de Polaris Dawn: cuenta regresiva, gráfica de cohete y la moneda de la comunidad en Solana.

## Abrir

`asteroid.html` es la página completa. Ábrela en el navegador.

`index.html` es una copia de esa página, junto con `.nojekyll`, para GitHub Pages. La dirección del sitio es https://borincanopr.github.io/asteroid-shiba/ después de activar Pages una vez en Settings → Pages → Deploy from a branch → branch `main`, carpeta `/` (root). Mientras Pages no esté activado, esa URL responde 404.

## Desarrollo

```bash
npm install
npm run dev
```

El servidor local queda en el puerto 8080.
